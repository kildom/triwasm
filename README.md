# uvm-wasm

<br clear="both" />

WebAssembly compiler for [µVM](https://github.com/kildom/uvm) - an embeddable, portable and minimalistic virtual machine.

The compiler compiles WebAssembly binary file into µVM binary or assembly file.

This is off-line compiler, which is opposite to JIT compilers that are normally used for WebAssembly execution.
