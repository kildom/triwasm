
# Features for v0.0.1

Included:

* Bulk memory operations
* Multi-value
* Mutable globals
* Basic optimizations
* Emulation of memory growth on guest side
* Non-trapping float-to-int conversions
* Sign-extension operations

NOT included:

* SIMD
* Extended constant expressions
* Reference types
* Tail calls
* Table growth
* Memory growth on host side
* Table import/export
* Global import/export
* Advanced optimizations
* Host callbacks
* Host resource management
* Externref (both value and tables)
* Funcref (just value, tables must be implemented)
* Exception handling
* Garbage collection
* Multiple memories
* Relaxed SIMD
* Threads and atomics
* Type reflection
