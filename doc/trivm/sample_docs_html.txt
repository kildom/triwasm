<h1>Core instruction set</h1>
<p>Core instruction set is aways available on triVM regadless of enabled extrensions.</p>
<h2>Binary operation instructions</h2>
<p>Following instructions do operation on two 32-bit integers.
The result is 32-bit integer pushed into the stack.</p>
<p>Division and modullo instructions (<code>UDIV</code>, <code>UMOD</code>, <code>SDIV</code>, <code>SMOD</code>) will cause a <a href="">Division By Zero</a> Fault if <code>value2</code> is zero.</p>

<h2>READ, WRITE</h2>
<p>Read or write an integer from the memory.</p>
<p>READ and WRITE instructions can access 8-bit, 16-bit or 32-bit values.
When reading 8-bit or 16-bit integer, the instruction can optionally sign-extend it to 32-bit integer.</p>
<table>
<thead>
<tr>
<th>Access bits</th>
<th>Encoding</th>
<th><code>width</code></th>
<th>Extend to 32-bits</th>
<th>Syntax</th>
</tr>
</thead>
<tbody>
<tr>
<td>32</td>
<td>Q and R (W=0)</td>
<td>4</td>
<td>-</td>
<td><code>READ …</code></td>
</tr>
<tr>
<td>16</td>
<td>S (W=0, B=0, S=0)</td>
<td>2</td>
<td>zero-extend</td>
<td><code>READ16 …</code></td>
</tr>
<tr>
<td>16</td>
<td>S (W=0, B=0, S=1)</td>
<td>2</td>
<td>sign-extend</td>

</tr>
<tr>
<td>8</td>

<p>Memory address is calculated with the formula: <code>address := base_address + width * offset</code>, where:</p>
<ul>
<li><code>offset</code> is encoded in instruction,</li>
<li><code>width</code> is a width of the access in bytes,</li>
<li><code>base_address</code> can be one of:</li>
</ul>
<table>
<thead>
<tr>
<th></th>
<th>Encoding</th>
<th>Syntax</th>
<th>Stack</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Zero</strong></td>
<td><code>base=0</code></td>
<td><code>WRITE offset</code></td>
<td><code>… value1 ⇒ …</code></td>
</tr>
<tr>
<td></td>
<td></td>
<td><code>READ offset</code></td>
<td><code>… ⇒ … value1</code></td>
</tr>
<tr>
<td><strong>Stack pointer</strong></td>
<td><code>base=1</code></td>
<td><code>WRITE [SP] + offset</code></td>
<td><code>… value1 ⇒ …</code></td>
</tr>
<tr>
<td></td>
<td></td>
<td><code>READ [SP] + offset</code></td>
<td><code>… ⇒ … value1</code></td>
</tr>
<tr>
<td><strong>Pop value</strong></td>
<td><code>base=2</code></td>
<td><code>WRITE [POP] + offset</code></td>
<td><code>… offset2, value1 ⇒ …</code></td>
</tr>
<tr>
<td></td>
<td></td>
<td><code>READ [POP] + offset</code></td>
<td><code>… offset2 ⇒ … value1</code></td>
</tr>
<tr>
<td><strong>AMB register value + pop value</strong></td>
<td><code>base=3</code></td>
<td><code>WRITE [AMB] + [POP] + offset</code></td>
<td><code>… offset2, value1 ⇒ …</code></td>
</tr>
<tr>
<td></td>
<td></td>
<td><code>READ [AMB] + [POP] + offset</code></td>
<td><code>… offset2 ⇒ … value1</code></td>
</tr>
</tbody>
</table>
  
  
<p><code>offset</code> in the instruction syntax can be omitted if it is zero.</p>
