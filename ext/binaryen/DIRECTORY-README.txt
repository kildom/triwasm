
===== Optimizer and compiler/toolchain library for WebAssembly  ====

This directory contains an external project: Binaryen.

It is used by the "tricc" tool to optimize WebAssembly module before
translating it into triVM bytecode.

Home Page: https://github.com/WebAssembly/binaryen
Releases:  https://github.com/WebAssembly/binaryen/releases
