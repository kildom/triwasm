
===== triVM SDK directory information ====

This directory contains external project: BareMetal WASM SDK.

It is used by the "tricc" tool to compile C/C++ source code. You can also use it for
your custom compilation to WebAssembly.

Home Page: https://github.com/kildom/baremetal-wasm-sdk
Releases:  https://github.com/kildom/baremetal-wasm-sdk/releases
